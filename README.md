# 量潮数据工程 (`quanttide-data`)

量潮第二大脑的数据工程领域仓库。涵盖数据工程相关的文档、数据、应用与工具，采用 Git 子模块架构统一管理。

## 目录

- `apps/` — 应用：`qtdata`（工具链）、`qtcloud-data`（数据云 CLI）
- `data/` — 陈述性记忆：archive、brochure、context、history、insight、intention、journal、library、profile、report、roadmap
- `docs/` — 程序性记忆：bylaw、essay、gallery、handbook、specification、tutorial
- `examples/` — 实验室：实验性/原型项目（default）
- `packages/` — 工具包：quanttide-agent-toolkit、quanttide-data-toolkit
